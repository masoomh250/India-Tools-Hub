UPLOAD:
1. Extract this ZIP.
2. In your GitHub repository, open the guides folder.
3. Upload all 19 HTML files into guides/.
4. Commit directly to main.
5. Update your existing sitemap.xml by adding the guide URLs from sitemap-with-guides.xml.
6. Do not request indexing for every page immediately. Google can discover them through the sitemap.
7. If you use manual indexing, prioritize a few important guides first.

IMPORTANT:
The package does not contain or modify your existing calculator pages.
The existing EMI and SIP guide files are included so the guides folder is complete.
