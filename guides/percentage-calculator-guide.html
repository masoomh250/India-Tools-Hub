What Is a Percentage?

A percentage expresses a number as a fraction of 100.

Percentage of a Number

To calculate X% of Y, multiply Y by X and divide by 100.

Percentage Increase or Decrease

Percentage change = (new value − old value) ÷ old value × 100. A positive result indicates an increase and a negative result indicates a decrease.

Percentage Example

For example, 20% of 500 is 100. If a value rises from 100 to 125, the percentage increase is 25%.

Common Percentage Mistakes

Always identify the reference or original value when calculating percentage change. A 20% increase and a 20% decrease are not exact opposites when applied successively.
