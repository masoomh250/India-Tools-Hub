How to Use the Percentage Calculator

Enter the values required for the calculation and click Calculate. The calculator provides several common percentage calculations on the same page.

What is X% of Y?

This calculation finds a percentage of a number.

Percentage Value = (Percentage ÷ 100) × Number

For example, 20% of ₹500 is ₹100.

X is What Percentage of Y?

This calculation tells you what percentage one number represents of another number.

Percentage = (X ÷ Y) × 100

For example, 25 is 12.5% of 200.

Percentage Increase or Decrease

Use the original value and new value to calculate how much the value has increased or decreased in percentage terms.

Percentage Change = ((New Value − Original Value) ÷ Original Value) × 100

A positive result indicates an increase, while a negative result indicates a decrease.

Adding or Subtracting a Percentage

You can calculate the result after increasing or decreasing a value by a specific percentage.

Increased Value = Base Value × (1 + Percentage ÷ 100)

Reduced Value = Base Value × (1 − Percentage ÷ 100)

Common Uses of Percentage Calculations

Percentage calculations are commonly used for discounts, GST calculations, salary increments, exam marks, profit and loss, price changes, business reports, investment returns and comparing values.

What is 20% of 500?

20% of 500 is 100.

How do I calculate percentage increase?

Subtract the original value from the new value, divide the result by the original value and multiply by 100.

How do I calculate percentage decrease?

Subtract the original value from the new value, divide the result by the original value and multiply by 100. A negative result indicates a decrease.

How do I find what percentage one number is of another?

Divide the first number by the second number and multiply the result by 100.

How do I calculate a discount percentage?

Divide the discount amount by the original price and multiply by 100.

How do I calculate a salary percentage increase?

Subtract the old salary from the new salary, divide the difference by the old salary and multiply by 100.

Can percentage calculations have decimal values?

Yes. You can use decimal numbers for both values and percentages.
